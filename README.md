# NexWeb Solutions Website

A responsive multi-page static website for NexWeb Solutions.

## Pages
- Home
- About
- Services
- Portfolio
- Pricing
- Blog
- Contact
- Privacy
- Terms

## Included features
- Responsive navigation + mobile menu
- Smooth reveal animations
- Animated counters
- Portfolio filters
- FAQ-ready component styling
- Pricing calculator
- WhatsApp enquiry and booking flows
- Contact form routing to WhatsApp
- Cookie preference notice
- Inline SVG logo
- SEO meta tags
- robots.txt + sitemap.xml

## Important
This is a static front-end site. The contact and booking forms open WhatsApp; they do not store submissions in a database.
Replace `YOUR-DOMAIN.example` inside `sitemap.xml` with your real domain.
Replace sample testimonials and demo portfolio projects with real client proof before publishing.
